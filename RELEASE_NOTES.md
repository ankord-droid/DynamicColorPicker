## Dynamic Color Picker v2.3.0

### Скачать
- **DynamicColorPicker-Setup-v2.3.0.exe** — установщик: ярлык в «Пуске», автозапуск с Windows (по желанию), удаление через «Приложения». Права администратора не нужны.
- **DynamicColorPicker-v2.3.0.exe** — портативная версия, один файл.

SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

### Новое в 2.3
- **Обучение** — пошаговый тур при первом запуске (повторить: ☰ → Обучение). Экран затемняется, нужная часть
  подсвечивается, в панели на время появляется тот компонент, о котором идёт речь, — его можно сразу попробовать.
  Объясняются круг и модели HSV / HSL / V-HSV, Luma-палитра, все виды слайдеров и чем они отличаются,
  инструменты цвета, режимы отображения, CSP, горячие клавиши. После тура панели возвращаются как были.
- **Свои гамут-маски** — кнопка формы маски → «Нарисовать новую маску»: точки ставятся кликами, тянутся,
  ПКМ — удалить, Enter — сохранить. Свои маски появляются в меню формы, их можно редактировать и удалять.
  Любую встроенную маску можно взять за основу («Редактировать как свою копию»).
- Исправлено: ошибки «Internal C++ object … already deleted» при работе с превью в редакторе панели.

### Новое в 2.2.1
- **Обновление простым запуском.** Скачайте новый exe и запустите: старая версия сама закроется с сохранением настроек,
  а новая предложит записать себя на место прежней копии — ярлыки и автозапуск продолжат работать.
- Повторный запуск той же версии не открывает вторую копию, а показывает уже открытую панель.
- Окно «Что нового» при первом запуске новой версии.
- **Папка данных на выбор** (Настройки → Система): настройки, палитры, референсы и журнал переносятся, например, на диск D.
  **Портативный режим:** папка `dcp-data` рядом с exe — всё хранится в ней.
- Установщик спрашивает папку установки.

### Новое в 2.2
- **Референс-доска** (☰ → Референс-доска или горячая клавиша) — окно поверх всех программ:
  несколько картинок с миниатюрами, вставка из буфера **Ctrl+V**, перетаскивание файлов, кнопка «Открыть»;
  масштаб колёсиком, ПКМ — двигать, отражение, оттенки серого для проверки тона;
  **ЛКМ — пипетка** (цвет сразу уходит в CSP), **Shift+ЛКМ — выделить область**;
  прозрачность окна и режим «сквозь клик»; картинки сохраняются между запусками
- **Генератор палитры** — из референса, выделенной области, буфера обмена или файла:
  основные цвета, яркие акценты, приглушённые, «свет / средние / тени»; сортировка по доле, тону, яркости;
  доля каждого цвета; сохранение в наборы и экспорт в .cls / .ase / .aco
- **Цвет освещения** в «Свет и тень»: нейтральный, солнце, закат, лампа, свеча, луна, пасмурно, неон или свой
- **Атмосфера** — слайдер «расстояние» сдвигает цвет к цвету воздуха (день, дымка, закат, сумерки, ночь, пыль, свой)
- **Контраст** — ΔL* и коэффициент контраста между основным и фоновым цветом с оценкой «читается ли силуэт»
- **Кожа и материалы** — рампы от глубокой тени до блика: 6 тонов кожи, золото, серебро, медь, сталь,
  деним, лён, бархат, шёлк, дерево, листва; или от текущего цвета с выбранным типом материала

### Новое в 2.1.2
- Проверка и загрузка обновлений идут через сетевой стек Windows: учитываются системные прокси, VPN и сертификаты. Время ожидания — до 25 секунд.
- Если `api.github.com` недоступен, версия определяется через страницу релиза на `github.com`.
- Понятное сообщение, если связаться с GitHub не удалось; подробности — в журнале.

### Новое в 2.1.1
- **Журнал ошибок** — `%USERPROFILE%\.dynamic_color_picker\log.txt`. Ошибки записываются с подробностями, программа при этом продолжает работать.
  ☰ → Журнал ошибок → «Открыть журнал» или «Скопировать отчёт для отправки».
- Исправлено: в exe без консоли любой вывод в консоль мог закрывать программу.

### Новое в 2.1
- **Пипетка с экрана** — кнопка в шапке или горячая клавиша: оверлей с лупой; отдельная клавиша мгновенно берёт цвет под курсором
- **Гамут-маска** — круг оттенок × насыщенность с маской (треугольник, острый, ромб, две зоны); вне маски цвета затемнены, выбор ограничивается маской; ПКМ — двигать, колёсико — повернуть, Ctrl+колёсико — размер
- **Гармонии** — дополнительные, раздельно-дополнительные, аналоговые, триада, тетрада, квадрат
- **Смешивание в OKLab** — A → (средний) → B, 3–15 шагов
- **Свет и тень** — оттенки со сдвигом тона: свет теплее и светлее, тень холоднее и темнее
- **Тональная шкала** — L* и ступень из 5/7/9; клик по ступени — тот же оттенок в этой яркости
- **Палитра холста** — цвета из выбранной области холста
- **Закреплённые цвета в истории** — ПКМ → «Закрепить»
- **Профили программ** — своя панель для CSP, Photoshop или другой программы
- **Резервная копия настроек** — ☰ → Резервная копия
- **Автообновление** — проверка GitHub Releases при запуске
- **Иконка и установщик**, автозапуск с Windows (Настройки → Система)

### Известные ограничения
- Протокол CSP Companion Mode неофициальный и может перестать работать после обновления CSP.
- Пока Dynamic подключён к CSP, смартфон в Companion Mode подключить нельзя.
