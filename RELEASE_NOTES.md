## Dynamic Color Picker v2.0.0

Плавающая модульная панель цвета для Clip Studio Paint и Photoshop.

### Скачать
`DynamicColorPicker-v2.0.0.exe` ниже — один файл, установка не нужна (Windows 10/11).
SmartScreen может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

### Возможности
- **Компоненты:** Color Wheel / Cube (HSV, HSL, V-HSV), Luma-Based Palette (Focused / Full), слайдеры RGB, HSV, V-HSV, HSL, LAB, LCH, CMYK, History, Foreground/Background/Transparent, Swatches
- **Наборы цветов:** импорт/экспорт `.cls` (CSP), `.ase`, `.aco`, `.gpl`, `.json`, `.txt`; извлечение из изображения с Extraction Accuracy
- **Панели:** до 4, редактор с перетаскиванием, тёмная и светлая темы, ширина и длина панели
- **Режимы:** Follow Mode, временное закрепление 📌, Pinned Mode; сторона появления у курсора
- **Управление:** глобальные горячие клавиши для отдельной клавиатуры / макропада, HoverAdjust (колёсико и клавиши), экранная цифровая клавиатура, перелистывание панелей кнопкой вызова
- **Связь с CSP** через Companion Mode (`File → Connect to smartphone`, QR считывается с экрана); Photoshop через COM

### Известные ограничения
- Протокол CSP Companion Mode неофициальный и может перестать работать после обновления CSP.
- Пока Dynamic подключён к CSP, смартфон в Companion Mode подключить нельзя.
