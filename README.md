# Dynamic Color Picker

Модульная панель работы с цветом для Clip Studio Paint и Photoshop.

## Скачать

Последняя версия: **[Releases](../../releases/latest)** — установщик `DynamicColorPicker-Setup-*.exe` или портативный `DynamicColorPicker-*.exe`.
Автосборка из `main` — пререлиз `latest`.

## Интерфейс

Плавающая тёмная карточка без рамки. Слева вкладки панелей (1, 2, +; ПКМ — переименовать/удалить),
справа сверху ☰ меню и 📌 закрепление. ☰ → «Настроить панель»: слева живое превью,
справа Components / Swatches — компоненты добавляются кликом или перетаскиванием, порядок меняется за ⠿.

## Возможности

**Компоненты** (собираются в редакторе перетаскиванием, в любом порядке)
- Color Wheel / Cube — модели HSV, HSL, V-HSV; вид «круг» или «куб»
- Luma-Based Palette — оттенки той же яркости L*, подсвеченный диапазон близкой яркости на слайдере; Full — весь спектр
- Color Sliders — RGB, HSV, V-HSV, HSL, LAB, LCH, CMYK
- History, Foreground/Background/Transparent
- Swatches — несколько наборов, импорт/экспорт **.cls (CSP), .ase, .aco**, а также .gpl/.json/.txt;
  извлечение из изображения с Extraction Accuracy

**Панели и вид** — до 4 панелей, тёмная и светлая темы, ширина и длина панели (дальше — прокрутка)

**Режимы отображения**
- Follow Mode — держите кнопку вызова: панель у пера, отпустили — исчезла (сторона появления настраивается)
- Временное закрепление (📌) — панель можно двигать, вызов приносит её к перу, после отпускания возвращается; сбрасывается при перезапуске
- Pinned Mode — панель всегда на экране, кнопка вызова показывает/скрывает

**Управление**
- Глобальные горячие клавиши для отдельной клавиатуры/макропада (☰ → Горячие клавиши): вызов, панели 1–4,
  следующая/предыдущая, HoverAdjust ±, оттенок/яркость/насыщенность ±, основной/фоновый, прозрачный, модель круга, добавить в набор
- HoverAdjust — колёсико или клавиши над кругом (оттенок), Luma-палитрой (яркость), слайдером (параметр); Shift — ×5
- Клик по числу у слайдера — экранная цифровая клавиатура
- Кнопка вызова, когда курсор над панелью, листает панели; колёсико над вкладками — тоже

**Инструменты цвета** — пипетка с экрана (лупа / мгновенно), гамут-маска, гармонии, смешивание в OKLab,
свет и тень, тональная шкала, палитра холста, закреплённые цвета в истории

**Живопись** — референс-доска (несколько картинок, Ctrl+V, пипетка, область, сквозь клик), генератор палитры,
цвет освещения, атмосферная перспектива, контроль контраста, кожа и материалы

**Система** — профили программ (своя панель для CSP / Photoshop), автозапуск, резервная копия настроек, автообновление, установщик

**Связь** — CSP через Companion Mode (`File → Connect to smartphone`), Photoshop через COM (Windows)

## Запуск из исходников

```
pip install PySide6 numpy opencv-python pynput pywin32
python dynamic_color_picker.py
```

Локальная сборка exe: `build.bat`.

## Примечание

Протокол CSP Companion Mode неофициальный, реализован по заметкам
[LumaPaletteCSP/PROTOCOL.md](https://github.com/andyubird/LumaPaletteCSP/blob/main/PROTOCOL.md).
Может перестать работать после обновления CSP.
